Насколько корректен мой readme? # Chatik — учебный клиент-серверный мессенджер

Данный проект представляет собой полноценный сетевой мессенджер, написанный на C++ с нуля. 
Использованы сокеты, многопроцессность (fork), многопоточность на клиенте, криптография (OpenSSL, AES-256-CBC), 
текстовый протокол. Сервер хранит данные в файловой системе без внешних БД. 
Клиент работает в консольном режиме с поддержкой команд.

Код собран под Linux, но при необходимости может быть адаптирован для macOS/WSL.

## Возможности

-  Регистрация и аутентификация с хэшированием паролей (SHA-256)
-  Личные сообщения между пользователями
-  Групповые чаты (создание групп, добавление участников)
-  Шифрование всего трафика после входа (AES-256-CBC)
-  Сохранение истории переписки на сервере (файл `history/history.dat`)
-  Офлайн-сообщения – доставка при следующем входе получателя
-  Защита от одновременного входа с одной учётной записью (lock-файлы в `data/online/`)
-  Консольный интерфейс с удобными командами


## Команды клиента (после аутентификации)

|               Команда              |                         Описание                      |
|------------------------------------|-------------------------------------------------------|
| `/users`                           | Показать список всех зарегистрированных пользователей |
| `/groups`                          | Показать список всех групп                            |
| `/newgroup <имя_группы>`           | Создать новую группу                                  |
| `/msg <пользователь> <текст>`      | Отправить личное сообщение                            |
| `/group <группа> <текст>`          | Отправить сообщение в группу                          |
| `/quit`                            | Завершить работу клиента                              |	

## Сборка и запуск
### Требования
- Компилятор с поддержкой C++17 (g++ версии 8 или новее)
- Библиотека OpenSSL (разработка)
- Утилиты `make`, `bash`

Установка зависимостей на Ubuntu/Debian:
```bash
sudo apt install build-essential libssl-dev
```
Сборка:
Склонируйте репозиторий и выполните скрипт инициализации:
```bash
git clone https://github.com/ktljhtp/messenger_TitovVD_pi31.git
cd messenger_TitovVD_pi31
bash setup.sh
```
Скрипт автоматически проверит наличие компилятора и OpenSSL, создаст необходимые директории (data, history), 
сгенерирует тестовых пользователей (alice:alice123, bob:bob123, charlie:charlie123) и выполнит сборку.

Запуск
Сервер (в отдельном терминале):
```bash
./messenger_server <порт>
```
Клиент:
```bash
./messenger_client
```

Известные ограничения и примечания
- При очень большом количестве одновременных клиентов (более 50) может 
наблюдаться снижение производительности из-за использования fork вместо потоков.
- История переписки хранится в одном файле, поэтому при накоплении миллионов 
записей операция /chat будет выполняться линейным поиском.
- Ключ шифрования сессии передаётся от сервера к клиенту в открытом виде после успешного логина. 
Для промышленного использования требуется обмен ключами по протоколу Диффи-Хеллмана или RSA.
- Пароли хэшируются по SHA-256 без соли – этого достаточно для демонстрации концепции, 
но не для реальной безопасности.
- При некорректном завершении клиента (не через /quit) сервер может не сразу освободить lock-файл; 
повторный вход станет возможным после таймаута или ручного удаления файла.
